# Neubrutalism（新粗野主义）

这是 [wuzf/2fa](https://github.com/wuzf/2fa) 项目的主题，不能单独运行：需要先部署 2FA（2.0.0 或更高版本），再在 **设置 → 外观与主题 → 主题 → 社区主题** 中安装。

新粗野主义 2FA 主题：账户排成大小不一的撞色便当盒方块，粗黑描边加硬阴影，「扫码添加」和「添加账号」在底部悬浮操作条里。支持手机屏幕及深色模式。

版本 **1.0.0**。需要支持 Theme API 2 / SDK API 1 的 2FA 主机。内部主题 ID 为 `neubrutalism-for-2fa`。许可与来源见 [NOTICE.md](NOTICE.md)。

## 安装

自己构建时，按下面的「源码构建」生成 `dist/2fa-theme.zip`，再在 2FA 的 **设置 → 外观与主题** 中导入，预览后应用。主题使用独立 ID，可与现有主题同时安装。

源码构建：

```sh
npm ci
npm run build
```

构建生成 `dist/2fa-theme.zip`、资源清单及 `2fa-theme.zip.sha256`。导入完整 ZIP；开发预览和测试数据不会进入安装包。

## 功能与设置

支持当前码与下一码复制、HOTP 核对恢复、账户操作菜单、搜索、服务筛选、排序、分组与平铺。添加账户、导入导出、备份、工具、设置和安全恢复均通过主机入口完成。主题读取主机已经生成的验证码，不自行计算 OTP。

主界面的常态全局按钮只有 **管理、视图**。添加账号放在“管理 → 账户与数据”中，仅空账户状态提供直接添加入口。服务筛选、排序和分组收在“视图”中；导入导出、备份、工具及明暗切换收在“管理”中。搜索和账户验证码保持直接可见。

| 设置     | 选项        | 默认 |
| -------- | ----------- | ---- |
| 信息密度 | 舒适 / 紧凑 | 舒适 |

语言、明暗模式、OTP 动效和业务偏好跟随主机。个人名称、说明、Logo、背景和页脚沿用主机品牌配置。支持公共静态外观的主机会同步使用主题字体、描边和硬阴影。主机的强调色同时用于按钮与文字链接，因此登录页及官方弹窗在浅色模式使用黑色强调、深色模式使用黄色强调，以保证可读性；主题自身的主要按钮保持黄色。

## 开发与验证

```powershell
npm ci
$env:HOST_ROOT = '../2fa'
npm test
npm run build
npm run test:host
npm run format:check
npm run dev
```

`HOST_ROOT` 指向主项目，用于真实导入器、导出器及 SDK 集成验证；未设置时相应测试会跳过。测试临时文件使用当前进程的 `TEMP` / `TMP`。

`npm run dev` 在 `http://127.0.0.1:4207` 启动本地合成预览。预览使用示例账户，不连接真实服务器，也不写真实剪贴板。点击添加、编辑等主机功能会显示预览说明；导入主题后的正式页面才会打开真实表单。正式账户变更、复制、离线缓存和会话状态由主机处理。
