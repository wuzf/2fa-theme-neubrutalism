# Neubrutalism — licenses and attribution

Neubrutalism is an independent theme for 2FA Theme API 2 / SDK API 1.

The account, command, navigation, internationalization and lifecycle adapter
is adapted from **Receipt / 2fa-theme-receipt**, which in turn adapts
**Pixel / 2fa-theme-pixel**, copyright (c) 2026 2FA Pixel contributors,
under the MIT License. The original license is preserved in
`licenses/Pixel-adapter-MIT.txt` and the root `LICENSE`.

The layout and CSS are part of this theme. Typography uses locally installed
system fonts; no font files or third-party images are bundled or fetched from
a CDN. All account data and OTP operations are supplied by the 2FA host SDK.

The release archive includes this notice and applicable MIT notices in
`licenses/`. Development-only packages and the synthetic preview SDK are not
included in the installable theme archive.
